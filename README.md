# KadDigital

Platform self-serve kad jemputan digital — kad scroll 4 halaman, tema dijana automatik
dari rujukan gaya client, motion pembukaan sebagai pilihan produk.

Baca `CLAUDE.md` dan `DEV HANDOFF DOCS/` sebelum mula kerja. Fasa pembinaan semasa ada
dalam `PROGRESS.md`.

## Skrip

```bash
pnpm dev        # jalankan server pembangunan
pnpm build      # build production
pnpm lint       # ESLint
pnpm typecheck  # tsc --noEmit
pnpm test       # Vitest (unit)
pnpm test:e2e   # Playwright (E2E)
```
